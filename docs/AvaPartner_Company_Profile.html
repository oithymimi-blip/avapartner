Section 05 · Part A

Security Architecture: Access Control, 2FA & KYC

Layers 1 – 3

Financial trust demands verifiable technical safeguards. AvaPartner protects client accounts, identity records, commission ledgers, and digital asset transfers through a five-layer defense-in-depth framework spanning client authentication, biometric KYC, and BNB Smart Chain custody.

Layer 1 · Access & Credentials

Authentication & Session Integrity

  • Bcrypt Password Hashing: Credentials hashed with bcrypt (10 salt rounds).
  • Signed JWT Sessions: 7-day signed tokens validated by strict auth middleware (requireAuth).
  • Email OTP & Recovery: 6-digit registration OTPs (10-min TTL) & single-use UUID password reset tokens (30-min TTL).
  • Admin Role Separation: Granular permission scopes (admin vs. subadmin role permissions).
  • Transport Hardening: Helmet HTTP security headers across all API routes.
Layer 2 · Withdrawal Lock

Google Authenticator (2FA TOTP)

  • 20-Byte Cryptographic Secret: Generated uniquely per user and paired via standard otpauth:// QR code or manual key.
  • Mandatory Withdrawal Check: When enabled, every withdrawal request strictly requires a live 6-digit TOTP verification code before funds reserve.
  • Protected Deactivation: Disabling 2FA requires verifying an active 6-digit code from the authenticator app.

Layer 3 — KYC / NID Identity Verification & 100-Point Account Strength

Users verify their identity using a National ID (NID), Passport, or Driving License alongside residential address verification and Front/Back document scans. When live selfie checks are active, the backend executes AWS Rekognition (CompareFaces) against the ID front photograph using a configurable biometric match threshold (default 90%).

Section 05 · Part B

Blockchain Treasury Custody, Checksums & Audit

Layers 4 – 5

Layer 4 — BEP-20 Deterministic Deposit Wallets & Smart Forwarders

On-Chain Deposit Detection & Sweeping

  • Permanent Deterministic Addresses: Each user receives a fixed, unique EVM deposit wallet derived via keccak256 from the master secret and user identity—never changing across sessions.
  • EIP-1167 Minimal Proxy Forwarders: Smart contracts (Forwarder.sol & ForwarderFactory.sol) securely flush BNB or BEP-20 USDT (0x55d3...7955) solely to the authorized Treasury Hot Wallet.
  • 5-Node BSC RPC Redundancy: Polls every 20 seconds across 5 independent BSC RPCs (publicnode, defibit, ninicoin, 1rpc, binance.org) with strict BigInt Wei idempotency (unswept_credited_wei) so deposits cannot double-credit.

Layer 5 — Data Integrity & Audit Resilience

  • ACID Financial Mutations: Wallet credits, IB commissions, trade settlements, and withdrawals execute inside atomic better-sqlite3 WAL transactions.
  • Immutable Activity Ledger: Every signup, trade, AI payout, KYC review, 2FA toggle, deposit, and withdrawal logs permanently to activity_logs.
  • Standardized Audit Timezone: All timestamps render in Bangladesh Standard Time (BDT, Asia/Dhaka, UTC+6) for unambiguous cross-ledger reconciliation.
  • Automated Snapshots & Cloud Sync: Full DB backups run every 6 hours (retaining 30 snapshots) plus graceful cloud persistence flushes on shutdown.
